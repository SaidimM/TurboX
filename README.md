# Turbo X — Anti-Gravity Championship

A 3D futuristic anti-gravity hovercraft racing game inspired by *TurboFly 3D*, built for Tuanjie 1.11 / Unity 2022.3 and the built-in render pipeline.

## Play in Unity / Tuanjie

1. Open `/home/ubuntu/projects/TurboX` in Tuanjie 1.11 or Unity 2022.3 LTS.
2. Open `Assets/Scenes/Solaris.unity` and press **Play** (or run **Turbo X → Create Circuit Pack Scene** from the menu bar).
3. Select your craft (**The Striker**, **Heavy Juggernaut**, or **Neon Flash**) and launch **Solaris Ridge**. Finish in the Top 3 to unlock the next circuit.

All 3D track ribbons, banked neon curbs, speed & weapon pads, hovercraft delta hulls, mountain ranges, and HUD elements are generated procedurally at runtime with zero external asset dependencies.

## Controls

- **A / D** or **Left / Right**: steer and bank across the ribbon
- **W / Up / Shift**: activate manual Turbo Boost (consumes rechargeable Turbo gauge)
- **S / Down**: airbrake
- **Space / F**: fire homing Pulse Missile (when picked up from a violet weapon pad)
- **R**: restart current race
- **P / Esc**: pause or resume
- **M**: open or close Craft & Circuit selector
- Touch screens display multi-touch steering, boost, and fire/brake controls.
